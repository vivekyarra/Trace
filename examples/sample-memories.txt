Trace Pattern #001
Source MR: !42 — Modernize type hints
Date: 2026-01-20
Rule: Use X | None instead of Optional[X]
Anti-pattern: typing.Optional[X]
Language: python
Reason: Optional is soft-deprecated in Python 3.10+; union syntax is clearer
Established by: @alice
Status: Active
Examples:
  Bad:  def get_user(id: int) -> Optional[User]:
  Good: def get_user(id: int) -> User | None:

Trace Pattern #002
Source MR: !65 — Enforce structured logging
Date: 2026-02-28
Rule: Use structlog with bound loggers instead of stdlib logging
Anti-pattern: import logging; logger = logging.getLogger()
Language: python
Reason: Structured logs enable automated parsing in Grafana Loki pipeline
Established by: @carol, @bob
Status: Active
Examples:
  Bad:  logger.info(f"User {user_id} logged in from {ip}")
  Good: log.info("user_login", user_id=user_id, ip=ip)
