Trace architecture

GitHub-native institutional memory, with CockroachDB as the recovery source and Amazon Bedrock as the constrained reasoning layer.

1. GitHubSigned issue and pull-request webhooks. HMAC, tenant, size, bot-loop, and replay checks fail closed.
2. CockroachDBAn agent task and outbox event commit atomically. Idempotency survives retries and process crashes.
3. SQS FIFOEncrypted durable delivery with bounded attempts, deduplication, DLQ retention, and CloudWatch alarms.
4. RetrievalVector candidates plus file scope, confidence, security relevance, feedback, and recorded selection provenance.
5. BedrockTitan creates 1024-dimensional embeddings. Nova Pro returns schema-constrained reasoning.
6. Governed resultTrace posts an attributable review or stores an ACTIVE/SUPERSEDED memory without erasing history.
Recovery boundary: CockroachDB is authoritative for tasks, memories, provenance, retrievals, audit events, and the transactional outbox. A GitHub delivery is not admitted until durable state commits.
